# Implementaciones GUAPA

Repositorio dedicado para compartir implementaciones de problemas básicos a miembros del Grupo Universitario de Algoritmia y Programación Avanzada (GUAPA).

## Consultar desde el navegador
Todo el material se puede leer (con código resaltado y botón de copiar) en el sitio web del club, sin necesidad de saber usar GitHub: **Settings → Pages** del repositorio muestra la URL.

## Estructura
- `implementaciones/`: código en C++ por categoría (grafos, strings, estructuras_de_datos…).
- `soluciones/`: soluciones de contests (`contest_01/`, `contest_02/`…).
- `docs/`: sitio estático (GitHub Pages).

Los archivos usan `snake_case` sin acentos ni espacios (ej. `prefix.cpp`).
