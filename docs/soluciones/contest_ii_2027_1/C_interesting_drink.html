Binary search Ordenamiento O(n log n + q log n) Memoria O(n)

Planteamiento

El problema nos dice que una persona quiere comprar su bebida favorita en una tienda. Hay n tiendas y quiere saber en cuántas la puede comprar si cada día tiene m_i monedas, y quiere saberlo durante q días.

Hacer una búsqueda completa y contar los lugares donde pueda comprar es demasiado para n,q=10^5 (sería O(n*q)). Por lo que podemos ordenar las tiendas y hacer una búsqueda binaria para poder encontrar la última tienda donde pueda comprar.

bool puede(ll m,ll x){//Esta es la condición que establecemos en la binaria.
    if(m<=x)return true;
    return false;
}
